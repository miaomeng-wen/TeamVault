## 按成员汇总

```dataview
TABLE length(rows) AS 认领数,
  length(filter(rows, (r) => r.reading_status = "unread")) AS 未读,
  length(filter(rows, (r) => r.reading_status = "reading")) AS 在读,
  length(filter(rows, (r) => r.reading_status = "finished")) AS 已完成
FROM "02_Literature"
WHERE assignee
GROUP BY assignee AS 成员
```

## 待认领（无认领人且未读）

```dataview
TABLE authors AS 作者, year AS 年份, source_type AS 类型, theme AS 主题, created AS 建档日期
FROM "02_Literature"
WHERE !assignee AND (reading_status = "unread" OR !reading_status)
SORT created ASC
```

## 在读中（谁在做什么）

```dataview
TABLE assignee AS 认领人, year AS 年份, source_type AS 类型, theme AS 主题
FROM "02_Literature"
WHERE reading_status = "reading"
SORT assignee ASC
```
